# USB 存储设备卡顿、读不出、推不出

## 现象

在本机上实测的一只 USB 3.0 U 盘（Fanxiang F325，安装盘兼数据盘）出现过：

- 插入后要很久才出现盘符，或只在 `ioreg` 里出现设备、Finder 里没有卷。
- 两个卷先后挂载，其中安装卷比数据卷晚了约 **9 分钟**。
- `diskutil list external physical` 长时间无输出、超时退出。
- 卷内容读不出，`MODE_SENSE_06 failed` 日志出现。
- Finder「推出」长时间没有完成，关机也会卡住。
- 把该盘拔掉之后，同样的磁盘操作恢复为几十毫秒级。

这些现象都发生在**该 U 盘被识别之后**，键盘、触摸板、摄像头等其它 USB 设备不受影响。

## 结论与边界

- 目前证据支持「该 U 盘在本机 macOS 下的存储路径不稳定」，**尚未确定**是盘本身、USB 端口、供电还是 macOS USB 存储驱动的问题。
- 因为手边只有这一只 U 盘，缺少第二只存储设备做对照，所以不能断言换一只盘一定正常。
- 在 `ioreg` 里能看到设备，不等于卷可用；必须以 Finder/`diskutil` 能否挂载和读取为准。

## 处理办法

1. 不要在这只盘还在读写时拔线。卡住时先等；必要时正常关机（关机也可能卡住，此时长按电源键强制关机，再拔盘）。
2. 引导用盘尽量只做引导：进系统后如果没有要读写的需要，可以在系统空闲时推出该盘，或者干脆让它不挂载。
3. 重要的安装器文件放内置 SSD 或另一只已知正常的 U 盘/移动硬盘。
4. 出现「先挂载一个卷、另一个卷迟迟不出现」时，不要反复点击 Finder 里的卷，否则会叠加未完成的磁盘请求。
5. 如果必须长期使用外置存储，优先选择有独立供电的硬盘盒，或换一只不同主控的 U 盘验证。

## 排查命令

```zsh
ioreg -p IOUSB -w0 | grep -i -A3 'F325\|Mass Storage'
log show --last 10m --predicate 'process == "kernel"' | grep -iE 'F325|MODE_SENSE|SCSI'
diskutil list external physical
mount | grep /Volumes
```

## 为什么不是 USB 端口映射的问题

本机 EFI 已包含 USBToolBox + UTBMap，安装器阶段键鼠、U 盘、摄像头都能枚举。存储设备的问题发生在 USB 存储协议与卷挂载阶段，与端口映射是两件事，修改 USB 映射解决不了它。
